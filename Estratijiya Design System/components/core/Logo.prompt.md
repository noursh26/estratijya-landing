Use `Logo` wherever the brand signs a surface. Never re-draw the mark in SVG or set "ESTRATIJIYA" in live type — the wordmark is lettering.

```jsx
<Logo tone="white" height={28} assetBase="../../assets" />
<Logo tone="green" markOnly height={20} assetBase="../../assets" />
```

- `assetBase` must be the relative path from the rendering page to `assets/`.
- Clear space around the lockup is at least the height of the mark.
- On brand photography use `tone="white"` over a scrim, never green.
